# TAGTAG
TAGTAG 是面向 Windows 的本地文件与文件夹标签管理器。受管资源始终是存储根目录中的原始、未加密普通文件；SQLite 只保存资源路径、索引、日志和一致性状态，不保存资源内容。

## 当前功能

- 首次启动必须选择一个全局存储根目录，未初始化不能进入工作区。
- 从选择器或主窗口拖放导入文件和文件夹，默认复制，也可明确选择移动。
- 在同一个导入窗口选择存储根内目标目录和零个或多个标签；零标签资源进入待整理区。
- 支持标签空间、无限层级、独立同名标签，以及同一唯一标签实体的多路径复用。
- 文件夹标签可显式启用动态子项继承；子项不产生直接标签副本，有效标签会标明继承来源。
- 同一受管资源可以属于多个标签空间，空间成员关系与标签关系相互独立。
- 支持名称/受管路径搜索、最近使用、常用标签、待整理和直接标签检查。
- 双击使用 Windows 默认应用打开资源，资源菜单可在 Explorer 中定位。
- SQLite 持久记录导入操作，复制/移动导入可以撤销；恢复原路径时绝不自动覆盖冲突内容。
- 每 15 秒扫描存储根结构，外部新增和受管资源缺失会显示一致性告警；普通内容编辑不告警。
- 全局备份包含 SQLite 在线快照、标签状态、用户设置、SHA-256 manifest 和原始资源层级。
- 支持校验完整备份并恢复到新的空存储根；成功后自动切换资料库，绝不覆盖当前根或非空目标。
- 支持将当前标签空间导出为带 SHA-256 清单的空间包，迁移标签、关系、历史和引用资源；稳定资源 ID 仅在类型与字节一致时复用。
- 支持导出不含资源与历史的空间模板；每次导入模板都会创建新的空间、标签和标签位置身份。
- 统一日志页按信息/提醒/警告分级配色，覆盖资源、标签、设置和一致性全部变化，支持关键词、级别和类别组合筛选；日志界面不再提供撤销入口。
- 搜索条件可命名保存并一键复用；常用标签可固定或隐藏；支持清理使用历史。
- 标签名称唯一性可按标签单独设置，也可全局默认唯一并单独豁免；同名独立标签有显式标注。
- 标签树支持拖拽调整层级、按深度展开/收起；支持标签实体合并与位置拆分。
- 导入可按全局命名模板重命名（含预览）；可按标签把资源手动整理到存储根内的标签目录，记录日志且领域层可撤销。
- 液态玻璃视觉：半透明磨砂面板、弹性动效、亮/暗主题；悬浮接收目标仅显示 LOGO，可拖动、靠边吸附并在拖放接近时给出动效。
- 高级检索支持名称、路径、类型、大小、创建/修改时间和标签 AND/OR/NOT 组合。

## 数据位置

- 全局存储根：由用户首次启动时选择。
- 资料库元数据：`<存储根>/.tagtag/tagtag.sqlite`。
- 标签状态和用户设置：`<存储根>/.tagtag/tagtag.sqlite`；旧版 `%APPDATA%/TAGTAG/` JSON 只在首次迁移时读取。
- 资源文件：直接位于存储根中，不进入数据库 BLOB、加密容器或应用专用文件包。

## 当前边界

- `Ctrl+Shift+T` 是 Windows 全局 Quick Tag 快捷键；关闭主窗口会隐藏到系统托盘，托盘菜单可显示窗口、开始 Quick Tag 或退出。安装版会注册文件和文件夹的 Explorer “使用 TAGTAG 添加标签”命令；设置中可选开启悬浮接收目标。
- 一致性告警支持接管/移出外部新增内容，以及显式配对后的接受新路径/恢复记录路径。
- 资源退出管理支持恢复原路径、移动到指定位置和 Windows 回收站，并提供日志与撤销。
- 不提供文件预览、正文全文检索、虚拟文件系统、内容寻址或透明去重。

## 本地开发


Windows 桌面插件构建需要符号链接支持。建议在 Windows 设置中启用 Developer Mode；本仓库不提交本机构建生成的插件链接或 `build/` 产物。

## 发布

`.github/workflows/release.yml` 支持手动构建。推送形如 `v0.10.0` 的 Git 标签时，标签版本必须与 `pubspec.yaml` 一致；工作流会运行分析与测试、构建 Windows Release，并同时发布 `TAGTAG-<tag>-windows-x64-portable.zip` 和 `TAGTAG-<tag>-windows-x64-setup.exe`。安装器按当前用户安装，不要求管理员权限；卸载不会删除用户选择的存储根或 `%APPDATA%/TAGTAG` 数据。

版本遵循 `MAJOR.MINOR.PATCH`：不兼容 API 或架构变更递增 `MAJOR`，向下兼容的新功能递增 `MINOR`，只修复缺陷且不增加功能时递增 `PATCH`。自 `v1.0.0` 起项目视为明确稳定；已经发布的历史标签和 Release 不重写。当前功能版本为 `v1.0.0`，其后纯修复版本从 `v1.0.1` 开始。

## 核心语义

标签实体由稳定 `tagId` 标识，标签在层级中的每次出现由 `placementId` 标识。唯一标签的多个位置共享同一个资源集合；名称相同但 `tagId` 不同的标签保持完全独立。资源与标签空间通过独立成员关系关联，不因清空标签而退出管理。
